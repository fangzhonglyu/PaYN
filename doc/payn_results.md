## INT throughput vs reduction length L (all bits in time)

For an A (BA-bit) x W (BW-bit) GEMM with reduction length L on a P_R x P_C grid of PEs (8 x 8 tiles, 64 outputs per PE per block):

    E(L)  = BA*BW*ceil(L/128) + (BA+BW-2) + (P_R+P_C-2) + 8*P_C      edges per block: data passes, laps, skew, drain
    GMAC/s/mm2 = 0.4 GHz * P_R*P_C*64*L / (E(L) * A_grid)  =  peak * U(L),   U(L) = BA*BW*(L/128) / E(L)

A_grid is the grid composite area of the Area section; the measured block periods equal E(L) for every measured point (regression and INT tables).  Other drains: replace 8*P_C by D (4*P_C both-way drain, 8 per-PE drain, ~1 overlapped).  Drain-register routes (DR): E(L) = max(BA*BW*ceil(L/128) + (BA+BW-2) + 2, 2*P_C), with their own measured area.  Accumulator range is not modelled, for PaYN or BOS (both 24-bit).  BOS: drain-excluded peak, independent of L.
