## Caveats

* The RTL is FlexPosit's 12 nm test-chip version (hardware/README.md of the FlexPosit repo): FP8 E4M3 activations and one accumulator per PE, not the paper's FP16 activations and 4-PE clusters sharing an FP16 accumulator.  The paper's own area/energy numbers (16 nm) are a different design point.
* Operands are uniform random codes (like the BOS benches), not LLM weight distributions; Posit activity depends on the weight distribution.
* FlexPosit scales only the weight precision; activations stay FP8.  BitMoD keeps INT8 or FP16 activations; PaYN scales both operands.  The operating points are not iso-precision.
* The 1,024 MAC/clock row is a grid of independent 8x8 cores.  One large FlexPosit array would amortize the per-column decoders and readout over more rows (see Area by block) but adds an N:1 row mux per column.
* The BitMoD rows are reported data, not reproduced in this project (PaYN_eval docs/MODELLING.md 2.3).
